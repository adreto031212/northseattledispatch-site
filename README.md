# northseattledispatch.com

Static landing site for the North Seattle Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py northseattle` in the RexMont ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `northseattle-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
